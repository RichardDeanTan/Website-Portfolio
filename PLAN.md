**Status:** live at **https://richard-dean-tanjaya.vercel.app** (deployed from `main` of github.com/RichardDeanTan/Website-Portfolio; every push redeploys). Phases 0–3 are done; Phase 4 has a few owner-side steps left (see the checklist in section 5).

## Context

The old site (https://richarddeantan.github.io/Personal-Portfolio/) was plain HTML/CSS/JS on GitHub Pages, with content that stopped at early 2025. The new CV added a lot that was missing:
- the **Data Engineer Intern role at PT Kalbe Farma** (Feb 2026 – present)
- **3 first-authored IEEE papers**
- the **Best Paper Award** (ITIS 2025)
- the **Dean's List**
- the **Rental Data Pipeline** project
- a much larger data-engineering skill set (Airflow, BigQuery, dbt, Terraform, GCP)

The goal was to rebuild the site in **Astro + TypeScript**, deploy it to **Vercel**, and keep the single-page structure and feel. Projects and Experience were redesigned, and the colours cleaned up so they look less like a generic AI template.

### Decisions
| Topic | Decision |
|---|---|
| Stack | Astro 7 (7.4.x, Node ≥ 22.23.4) + TypeScript (strict), plain scoped CSS (no Tailwind), static output on Vercel |
| Layout | Single page. Order: Home, About, **Publications, Projects**, Experience, Contact (Publications moved before Projects in Phase 3). Projects and Experience redesigned |
| Colour | Keep dark + blue, no purple gradient. Soft accent glow on hover/focus only (restored in Phase 3 at the owner's request) |
| Theme | Light and dark. Always starts in **light**, whatever the OS setting; dark only when the visitor picks it with the header toggle, which remembers the choice (changed after launch) |
| Motion | Typewriter, scrolling logo strip, accordion slide, hover glow. Reduced motion is **softened, not removed** (Phase 3 decision; see section 2) |
| Publications | Section of its own |
| Contact form | Web3Forms (sends to the owner's inbox) |
| Project images | Unsplash placeholders for now; real screenshots later |
| Experience entries | Kalbe Farma, Researcher, DS Club R&D, Binus Mentor. Education shown as separate cards: BINUS and SMAK Penabur Kota Wisata (high school re-added after launch) |

## 1. Tech stack and repo structure

- **Astro 7** generates a static site. `"engines": { "node": ">=22.23.4" }` in package.json keeps Vercel on a compatible Node. It ships almost no JavaScript; each interactive part is a small TS `<script>` inside its component.
- **TypeScript strict**: every piece of content is a typed object, so a missing or misspelled field fails `npm run build`.
- **Content is kept apart from layout**: edit `src/data/*.ts` to update the site, not the components.
- **Assets**: `@fontsource/poppins` (self-hosted), `@fortawesome/fontawesome-free` (UI icons), `devicon` (skill logos imported as local SVGs, no CDN).
- **Integrations**: `@astrojs/sitemap`, `astro:assets` for image optimisation (Unsplash hosts allowed in `astro.config.mjs`). Astro's dev toolbar is disabled.

## 2. Design system

### Colour tokens
Every colour is a variable in `tokens.css`, with a dark set under `[data-theme="dark"]`. There is no OS-based fallback: without JavaScript the site is light. No gradients. There is **one accent colour**, used on the primary button, active nav link, text links, metric numbers, filter state and the "current role" marker.

| Token | Light | Dark | Used for |
|---|---|---|---|
| `--bg` | `#FFFFFF` | `#0B0D10` | page background |
| `--surface` | `#F5F7FA` | `#14171C` | cards, alternating (grey) sections |
| `--border` | `#E3E7ED` | `#343B47` | card borders, dividers (dark brightened from `#252A33` in Phase 3) |
| `--border-strong` | `#7A8392` | `#5F6775` | form field borders (3:1 against both backgrounds) |
| `--text` | `#0B0D10` | `#F2F4F7` | body and headings |
| `--muted` | `#525B69` | `#A0A7B4` | dates, secondary text, placeholders |
| `--accent` | `#0B6FB0` | `#38A8E8` | the single accent |
| `--on-accent` | `#FFFFFF` | `#0B0D10` | text on accent buttons |
| `--glow` | accent at 45% | accent at 45% | hover/focus glow |

All text and accent pairs pass WCAG AA (4.5:1) on both `--bg` and `--surface`; checked with the contrast tool in Phase 3.

### Type, shape and motion
- **Font**: Poppins (continuity with the old site). Headings 600–700, body 400, line-height 1.65.
- **Headings** are solid text colour; the highlighted word ("My **Projects**") uses the accent.
- **Radius**: 8px cards, 6px chips. The primary CTA is the only pill-shaped element.
- **Depth**: cards are flat with a 1px border. Buttons, icon links, filters, project cards, contact rows and the header photo get the accent glow on hover/focus; buttons and social icons also lift 2px, project cards 4px. Only the open project dialog has a real shadow.
- **Motion**: typewriter, looping tech carousel (pauses on hover/focus), fade-up scroll reveal, `<details>` slide-open with rotating chevron, hover lift and glow.
- **Reduced motion** (Phase 3 decision: soften, don't remove): when the OS asks for reduced motion, the typewriter, carousel, accordion slide and glow still run; only the slide-up on scroll and the hover lifts are dropped. Reason: the owner's Windows has "Animation effects" off, and a full kill switch made the site completely static for them.

### Theme toggle
- An inline script in `<head>` sets `data-theme` before paint: `dark` only if `localStorage.theme` is `dark`, otherwise `light`. The OS `prefers-color-scheme` is ignored.
- The `theme-color` meta (browser UI colour) follows the active theme.
- The header toggle is a sun/moon button with an `aria-label`.

### Projects
1. **Filter bar**: All · Data Engineering · Machine Learning · Deep Learning & NLP · Data Analytics, each with a count. Real `<button>`s with `aria-pressed`; a polite live region announces the result count.
   - The URL remembers the filter: `/?filter=de#projects` can be shared (a query string, so `#projects` still scrolls).
2. **Featured row**: Rental Data Pipeline and Indonesian Stock Sentiment Analysis as large horizontal cards (stacked on mobile) with a summary, highlighted key result, all tech chips, a **Details** button and GitHub / Live buttons.
3. **Grid of compact cards** for the other 11: 3 columns on desktop, 2 on tablet, 1 on mobile. Each card: 16:9 image, category label, title, 2-line summary, optional metric (e.g. `90%` F1-macro), up to 3 tech chips plus `+n`, GitHub / Live icons. The whole card opens the dialog.
4. **Detail dialog** (native `<dialog>`, one per project): image, Overview, What I did, Results, tech chips, related paper, links. Esc, the × button or a backdrop click closes it, and focus returns to the card. The Live button is hidden when `liveLink` equals `repoLink`.
5. **Data model** (`types.ts`):

   ```ts
     categories: ('de' | 'ml' | 'dl' | 'analytics')[];

     highlight?: string;            // featured-card key result
     image: string; imageAlt: string;
     repoLink?: string; liveLink?: string; liveLabel?: string;
     publicationId?: string; featured?: boolean;
   }
   ```
